### [Computer Science Projects](https://github.com/Alyzzini/computer-science-projects)

### [Fishing Helper](https://github.com/Alyzzini/fishing-helper)
**Python · Tkinter · NumPy · Pillow · Windows API**

A desktop computer-vision project for a fishing minigame. It tracks a moving target, reads percentage text locally, and coordinates mouse and keyboard input. The source separates capture, tracking, text recognition, and input handling, with regression tests and documented limits.

### [Skyfall Rush](https://github.com/Alyzzini/skyfall-rush)
**Luau · Roblox Studio · Rojo**

An obstacle-course game prototype with server-controlled race timing, checkpoints, cosmetics, and persistence code. The repository includes a Studio download, an architecture overview, and the remaining gameplay and live-data validation work.
